Engage Island — playable preview

Build {{CANDIDATE}}

The game runs from a small web server on your Mac — opening the game files directly will not work. It needs one of: Node.js 18+ or Python 3. Nothing is downloaded or installed by this preview.

Play on this Mac

  1. Open Terminal (Applications → Utilities → Terminal).
  2. Type cd (with a space), drag this Engage-Island-Playable-Preview folder onto the Terminal window, and press Return.
  3. Start the server with one of these, then press Return: 
    node serve.mjs
    or 
    python3 serve.py
    Not sure which you have? node --version or python3 --version. If macOS offers to install “command line developer tools” for python3, you can cancel and use Node instead (nodejs.org).
  4. In Safari or Chrome on this Mac, open http://127.0.0.1:8089/start.html — it has the three buttons: Start with the Friend picker, Reduced motion, Replay the opening with Doug.

Stop it

Click the Terminal window and press Control-C. Closing the window also stops it.

Optional: play on an iPad or phone (same Wi-Fi)

  1. Stop the server if it is running, then start it with --lan: 
    node serve.mjs --lan
    or python3 serve.py --lan. If macOS asks whether to allow incoming network connections, choose Allow.
  2. Terminal prints an address like http://192.168.1.23:8089/start.html. Type that address into Safari on the iPad or phone. (Do not use 127.0.0.1 or localhost on the iPad — that would mean the iPad itself.)
  3. Both devices must be on the same Wi-Fi. Some guest or office networks block device-to-device connections; if the page will not load, that is the likely reason.
  4. While it runs with --lan, anyone on the same Wi-Fi could open the page. Stop it with Control-C when you are done. Nothing is put on the internet.

Other notes

  • Port 8089 busy? Add --port 9000 and use :9000 in the address instead.
  • Sound is placeholder only (a short tone for Captain Pete). Mute is remembered by the browser.
  • The Friend picker starts fresh every time the page loads — reload to replay from the start.
  • The game makes no requests outside this server while it runs.
  • Real-device smoothness hasn't been checked yet — that is what your try-out is for.
